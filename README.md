# ai-navy-march-contest
ai 군가 공모전 설계용

가사 설계 전
1. 군함행진곡, 바다로가자, 앵카송의 주요 키워드 파악하기.
2. 기존 군가의 박자 파악하기 ex) 4/4
3. 군가의 어절 개수 파악 후 설계할 어절 개수 정의하기
4. 종결어미 위치 정의하기
<br>
예시) <br>
3 4 3 3 <br>
3 4 2 3 -> 끝에 다 사용 <br>
3 4 3 2 <br>
3 2 2 3 2 -> 끝에 다 사용 <br>

후렴 <br>
3 4 2 3 <br>
3 2 2 5 or 3 2 2 3 2-> 끝에 다 사용 <br>

5. 가사 작성하기
6. 절과 후렴이 제대로 이어지는지 파악하기
7. 새로운 절과 기존 절간 중복이 발생하는지 파악하기

- [x] 가사 작성 완료


8. 군가 다운로드 (군함행진곡, 바다로 가자)
9. 두 군가 mashup하기 단 suno ai가 mashup한 음정피치를 그대로 따라가면 안되기 때문에 mashup 결과물에 보컬 목소리 제거하기
10. mashup 결과물과 가사 스타일 suno에 업로드
11. suno를 활용하여 군가 생성하기 (가사를 넣을 경우 ai가 새로운 피치로 부르게됨)
- [x] 군가 생성 완료

12. 기존 군가와 비교 하였을 때 괜찮은지 비교
- 점검결과: 군함행진곡이 너무 명곡이라 이기기 힘듬


13. ai로 영상을 만들어야함 스마트폰 환경의 제약이 있고, 비용 절감을 목적으로 상용 플랫폼 대신 wan 2.2를 무제한으로 제공하는 사이트가 있으니, 해당 사이트 이용하여 클립들을 제작하기
14. 편집 어플을 활용하여 여러 클립을 조합하여 군가 영상 만들기
