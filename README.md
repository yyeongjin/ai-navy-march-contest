# ai-navy-march-contest
ai 군가 공모전 설계용

가사 설계 전
1. 군함행진곡, 바다로가자, 앵카송의 주요 키워드 파악하기.
2. 기존 군가의 박자 파악하기 ex) 4/4
3. 군가의 어절 개수 파악 후 설계할 어절 개수 정의하기
4. 종결어미 위치 정의하기
<br>
예시) <br>
3 4 3 3 <br>
3 4 2 3 -> 끝에 다 사용 <br>
3 4 3 2 <br>
3 2 2 3 2 -> 끝에 다 사용 <br>

후렴 <br>
3 4 2 3 <br>
3 2 2 5 or 3 2 2 3 2-> 끝에 다 사용 <br>

5. 가사 작성하기
6. 절과 후렴이 제대로 이어지는지 파악하기
7. 새로운 절과 기존 절간 중복이 발생하는지 파악하기

- [x] 가사 작성 완료


임시 메모
- suno를 활용하여 만드는 방식은 너무도 싫음 대안으로 OpenUtau를 사용하여
직접 피치를 조절하여 무반주 입노래를 만들 생각
- audio to audio 모델등을 활용하여 군가 배경음 제작
- 무반주 노래와 배경음 합칠 생각
